# Ride Routes

**Descubra rotas, explore paisagens e conheça os destinos do Geoparque Raízes de Pedra sobre duas rodas.**

O Ride Routes é uma plataforma voltada à divulgação de rotas de cicloturismo no Geoparque Raízes de Pedra. A proposta é reunir informações que ajudem ciclistas a conhecer os percursos, explorar pontos de interesse e planejar suas experiências.

A plataforma busca valorizar o turismo regional, incentivando a exploração do território por meio do cicloturismo e facilitando o acesso a informações sobre as rotas e seus atrativos.

## Objetivos

- Divulgar rotas de cicloturismo do Geoparque Raízes de Pedra.
- Facilitar o acesso a informações relevantes para o planejamento dos percursos.
- Destacar pontos de interesse e atrativos turísticos da região.
- Incentivar o cicloturismo e a valorização do patrimônio natural e cultural local.

## Funcionalidades previstas

- **Apresentação do projeto:** página inicial com informações sobre o Ride Routes e a região.
- **Exploração de rotas:** páginas dedicadas a cada percurso, com informações e imagens.
- **Informações dos percursos:** identificação dos pontos de início e fim e outras características relevantes.
- **Gráficos de altimetria:** visualização do perfil de elevação das rotas.
- **Pontos de interesse:** informações sobre locais relevantes e atrativos turísticos ao longo dos percursos.

*As funcionalidades estão previstas e serão desenvolvidas progressivamente.*

## Público-alvo

O projeto é destinado a praticantes de cicloturismo, tanto individualmente quanto em grupos e comunidades, que desejam conhecer novas rotas e explorar os atrativos do Geoparque Raízes de Pedra.

## Sobre o projeto

O Ride Routes surgiu inicialmente como um projeto acadêmico desenvolvido no contexto de uma bolsa de estudos.

Posteriormente, decidi retomar a iniciativa de forma independente, fora do contexto acadêmico, com o objetivo de reconstruir e aprimorar a aplicação. Esta nova etapa busca utilizar tecnologias atuais, melhorar a organização do projeto e estabelecer uma base que permita sua evolução e expansão.

A proposta é dar continuidade à ideia original, ampliando seu potencial como plataforma de divulgação de rotas de cicloturismo e de valorização dos atrativos turísticos do Geoparque Raízes de Pedra.

## Desenvolvimento local

### Pré-requisitos

- Node.js
- pnpm
- Uma instância do PostgreSQL configurada para o projeto.

### Instalação

Clone o repositório e acesse a pasta do projeto. Em seguida, instale as dependências:

```bash
pnpm install
```

Configure as variáveis de ambiente necessárias no arquivo `.env`, conforme a configuração do projeto.

Execute os comandos de configuração do banco de dados e do Prisma definidos no projeto.

Inicie o servidor de desenvolvimento:

```bash
pnpm dev
```

A aplicação estará disponível em `http://localhost:3000`.
